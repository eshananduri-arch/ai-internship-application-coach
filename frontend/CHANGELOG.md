# Changelog

## 1.0.0 — 2026-10-31

- Initial Firstrole frontend with an empty upload screen and no pre-generated letter.
- One-page PDF/DOCX selection, company selection, dependent internship roles and signature name.
- Generation progress, API errors, editing, exact-version confirmation, approval/rejection and server-export download UI.
- Justified cover-letter body paragraphs with left-aligned greeting and signature.
- Responsive layouts, keyboard focus feedback and reduced-motion support.
- Local public catalog containing 15 fictional roles for development.
- Frontend browser checks using synthetic API responses.

This release does not include a running Python API, PostgreSQL connection, live AI generation or public deployment. Approval and downloads require their corresponding backend endpoints.
